Dokumentasi API

Ambil data transaksi parkir dalam format JSON untuk sistem lain: rekap dan detail.

Mulai API key Autentikasi Endpoint Rekap transaksi Detail transaksi Referensi Kode error

API key

Satu key per akun audit. Key lama langsung tidak berlaku saat dibuat ulang atau dicabut.

Memuat…

Salin dan simpan API key ini sekarang. Demi keamanan, key hanya ditampilkan sekali.

Autentikasi

Semua permintaan memakai metode GET dan API key di header.

Kirim API key lewat header X-API-Key (atau Authorization: Bearer <key>). Jangan taruh key di URL.

Base URL

Ketentuan

• Data yang dikembalikan sama dengan dashboard audit: hanya transaksi parkir tiket selesai, sebanyak akses data -% akun ini.
• Tanggal memakai format YYYY-MM-DD dan mengacu ke tanggal buku. Rekap dan detail hanya 1 hari per permintaan (parameter tanggal); tanpa parameter memakai tanggal buku berjalan. Untuk beberapa hari, panggil per tanggal.
• Nominal dalam Rupiah (bilangan bulat), durasi dalam menit.
• Batas permintaan: 120 per menit per alamat IP.

Rekap transaksi

Ringkasan 1 hari (satu tanggal buku): pendapatan, per jenis kendaraan, per metode bayar, dan perbandingan dengan hari sebelumnya.

GET/api/audit/v1/rekap

qFilter no. tiket atau nopol. Opsional.

Detail transaksi
Daftar transaksi per baris untuk 1 hari (satu tanggal buku), terbaru di atas, dengan halaman (pagination).

        

          
GET/api/audit/v1/detail

          
Parameter

          

            
NamaKeterangan

            
              
tanggalTanggal buku (YYYY-MM-DD). Opsional, default tanggal buku berjalan. Hanya 1 hari; parameter dari/sampai ditolak.

              
qFilter no. tiket atau nopol. Opsional.

              
pageNomor halaman, mulai 1. Default 1.

              
per_pageBaris per halaman, 1–500. Default 100.

Kode error

StatusArti

            
              
400Parameter salah, misalnya format tanggal salah, atau dari/sampai dikirim (hanya tanggal yang didukung).

              
401API key tidak dikirim, salah, sudah dicabut, atau akun audit nonaktif.

              
404Endpoint tidak ditemukan.

              
405Metode selain GET.

              
429Terlalu banyak permintaan. Tunggu sesuai header Retry-After (detik).
